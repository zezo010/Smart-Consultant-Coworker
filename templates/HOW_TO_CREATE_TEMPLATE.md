# كيفية إنشاء قالب DOCX لـ HexaGen GRC

## 🎯 دليل سريع خطوة بخطوة

---

## الخطوة 1: فتح Microsoft Word

1. افتح Microsoft Word
2. اختر "مستند فارغ" (Blank Document)

---

## الخطوة 2: تصميم الهيكل الأساسي

### العنوان الرئيسي

```
{{HX.POLICY_NAME_AR}}
{{HX.POLICY_NAME_EN}}

{{HX.CLIENT_NAME_AR}}
{{HX.ISSUE_YEAR}}
```

**النتيجة**:
- اكتب هذه الأسطر في أعلى المستند
- اجعل النص الأول بخط كبير (20-24pt)
- ضع النص العربي محاذاة لليمين
- ضع النص الإنجليزي محاذاة لليسار

---

## الخطوة 3: إنشاء جدول المعلومات

### في Word:
1. Insert → Table → 2 columns x 7 rows
2. املأ الجدول:

| الحقل (العمود الأيسر) | القيمة (العمود الأيمن) |
|----------------------|----------------------|
| رقم الوثيقة | {{HX.DOC_ID}} |
| الإصدار | {{HX.VERSION}} |
| تاريخ الإصدار | {{HX.ISSUE_DATE}} |
| تاريخ المراجعة القادم | {{HX.NEXT_REVIEW_DATE}} |
| التصنيف | {{HX.CLASSIFICATION}} |
| إشارة المشاركة | {{HX.SHARING}} |
| نطاق التطبيق | {{HX.APPLICABILITY}} |

### تنسيق الجدول:
- لون خلفية الصف الأول: أزرق فاتح
- العمود الأيسر (التسميات): **Bold**
- محاذاة: النصوص العربية → يمين
- حدود: 1pt, أسود

---

## الخطوة 4: إضافة منطقة المحتوى

بعد الجدول، أضف:

```
{{HX.POLICY_CONTENT}}
```

**ملاحظة**: هذا هو المكان الذي سيُدرج فيه المحتوى المُولَّد

---

## الخطوة 5: إضافة المراجع

في نهاية المستند:

```
المراجع والمعايير
{{HX.REFERENCES}}
```

---

## الخطوة 6: معلومات الاتصال (اختياري)

```
للاستفسارات والتواصل:
{{HX.CONTACT_INFO}}
```

---

## الخطوة 7: جدول الاعتمادات (اختياري)

أنشئ جدول 3 columns x 4 rows:

| الاسم | المنصب | التاريخ |
|------|--------|---------|
| **المُعِد** | {{HX.PREPARED_BY}} | {{HX.ISSUE_DATE}} |
| **المراجع** | {{HX.REVIEWED_BY}} | - |
| **المعتمد** | {{HX.APPROVAL_NAME}} | {{HX.APPROVAL_DATE}} |

مع إضافة سطر للتوقيع:

```
المنصب: {{HX.APPROVAL_TITLE}}
```

---

## الخطوة 8: إعدادات الصفحة

### للوثائق العربية:

1. **Layout** → **Margins** → Normal (2.5cm كل الجوانب)
2. **Layout** → **Orientation** → Portrait
3. **Layout** → **Size** → A4

### إعدادات الخط:

- **العربي**: Sakkal Majalla أو Arial
- **الإنجليزي**: Arial أو Calibri
- **حجم النص الأساسي**: 12pt
- **حجم العناوين**: 14-16pt

### إعدادات الفقرة (للنص العربي):

1. Home → Paragraph → Dialog Box Launcher
2. اختر **Alignment**: Right
3. اختر **Text direction**: Right-to-left

---

## الخطوة 9: إضافة Header & Footer (اختياري)

### Header (أعلى الصفحة):

```
{{HX.CLIENT_NAME_AR}}
{{HX.POLICY_NAME_AR}}
```

### Footer (أسفل الصفحة):

```
{{HX.DOC_ID}} | الإصدار {{HX.VERSION}} | صفحة {PAGE} من {NUMPAGES}
```

**كيفية إضافة رقم الصفحة**:
1. Insert → Page Number → Bottom of Page → Plain Number 3
2. عدّل النص ليشمل المعلومات أعلاه

---

## الخطوة 10: حفظ القالب

1. **File** → **Save As**
2. **الموقع**: `templates/policies/`
3. **اسم الملف**: `policy_template_ar.docx`
4. **نوع الملف**: Word Document (*.docx)
5. اضغط **Save**

---

## ✅ قائمة التحقق النهائية

قبل حفظ القالب، تأكد من:

- [ ] جميع الـ placeholders صحيحة ({{HX.VARIABLE_NAME}})
- [ ] لا توجد أخطاء إملائية في التسميات الثابتة
- [ ] التنسيق متسق في كل الصفحة
- [ ] الخطوط مناسبة للغة العربية
- [ ] المحاذاة صحيحة (يمين للعربي، يسار للإنجليزي)
- [ ] الجداول منسقة بشكل جيد
- [ ] Header & Footer يعملان بشكل صحيح
- [ ] الهوامش مناسبة

## 🎨 نصائح التصميم

### 1. الألوان

استخدم نظام ألوان احترافي:
- **الأزرق الداكن** (#003366) للعناوين الرئيسية
- **الأزرق الفاتح** (#E6F2FF) لخلفية الجداول
- **الرمادي** (#666666) للنصوص الثانوية
- **الأسود** (#000000) للنص الأساسي

### 2. المسافات

- مسافة بين الفقرات: 6pt قبل، 6pt بعد
- تباعد الأسطر: 1.15 أو 1.5
- مسافة بين الأقسام: 12-18pt

### 3. العناوين

استخدم Styles للعناوين:
- **Heading 1**: 16pt, Bold, لون داكن
- **Heading 2**: 14pt, Bold
- **Heading 3**: 12pt, Bold

### 4. القوائم

- استخدم Bullets للقوائم غير المرتبة
- استخدم Numbering للخطوات المتسلسلة
- اجعل المسافة بين عناصر القائمة 3-6pt

## 🎓 للمستوى المتقدم

### استخدام Content Controls

بدلاً من placeholders بسيطة، يمكنك استخدام Content Controls:

1. **Developer** tab → **Design Mode**
2. أدخل **Plain Text Content Control**
3. في Properties، اجعل Tag = `HX.VARIABLE_NAME`
4. هذا يحافظ على التنسيق بشكل أفضل

### استخدام Building Blocks

لأقسام متكررة:
1. حدد القسم
2. Insert → Quick Parts → Save Selection to Quick Part Gallery
3. استخدمه في قوالب أخرى
